FIXES
- Pending Job Card order selector uses sales quantity minus linked Job Card quantity. Fully allocated orders disappear; partially allocated orders show the remainder.
- Database guard rejects over-allocation, including a stale order selection. Existing records are not rewritten.
- Item create/edit supports Add New Colour. Colours are normalized and deduplicated; after saving the item they are available from saved variants on other devices. Unsaved colours are not a standalone colour master.
- Attachment URL updates check actual database errors and zero-row updates. Upload errors no longer silently pass as successful attachment saves.
- Measurement link updates parent item state and synchronizes when the selected item changes.
- Excel MIME types are added to the existing item-images bucket allow-list without removing old types or changing storage policies. Unrestricted allow-lists remain unrestricted.
- Storage upload requests participate in loading/error feedback. Item load failures show an error instead of an empty item list.
